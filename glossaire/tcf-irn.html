TCF IRN

Test de Connaissance du Français — Intégration, Résidence, Nationalité

Définition

Le TCF IRN est le test de français conçu spécifiquement pour les démarches d'intégration, de titre de séjour et de nationalité. C'est la voie la plus utilisée pour prouver son niveau dans un dossier de naturalisation.

Il évalue quatre compétences : compréhension orale, compréhension écrite, expression orale et expression écrite. Depuis le 1er janvier 2026, le niveau exigé pour la naturalisation est le B2.

Où vous le rencontrez

  • Au moment de constituer le dossier : l'attestation fait partie des pièces obligatoires.
  • Dans les centres agréés : le test se passe uniquement dans un centre habilité, sur inscription.

Ce qu'il faut faire

  • Vérifiez la validité de deux ans avant de déposer : une attestation périmée au moment du dépôt rend le dossier incomplet.
  • Comparez les tarifs entre centres de votre région : ils varient sensiblement pour un test identique.
  • Prévoyez le délai de résultat (environ quatre semaines) dans votre calendrier de dépôt.

Erreurs fréquentes

  • Confondre le TCF IRN avec les autres versions du TCF : seule la version IRN est adaptée à ces démarches.
  • Passer le test trop tôt. Deux ans de validité peuvent expirer pendant la constitution d'un dossier qui prend des mois.
  • Négliger l'expression écrite. C'est l'épreuve où l'écart entre B1 et B2 se creuse le plus, et celle qui fait le plus souvent manquer le niveau.

Questions fréquentes

Quelle est la différence entre le TCF IRN et le DELF B2 ?

Le TCF IRN est un test dont l'attestation vaut deux ans ; le DELF B2 est un diplôme valable à vie. Le DELF coûte généralement moins cher mais s'organise à dates fixes.

Le TCF IRN est-il valable combien de temps ?

Deux ans. C'est la date de dépôt du dossier qui compte, pas la date de la décision.

Peut-on repasser le TCF IRN si le niveau B2 n'est pas atteint ?

Oui, il n'y a pas de limite au nombre de tentatives. Chaque passage est payant, d'où l'intérêt de se situer avec un test blanc avant de s'inscrire.
